# Hangman Game

## Overview

This project is a Python-based Hangman Game developed as part of the CodeAlpha Python Programming Internship. The game randomly selects a word and provides a hint to the user. The player must guess the word one letter at a time within a limited number of attempts.

## Features

* Random word selection
* Hint system
* Limited attempts for guessing
* Score tracking
* User-friendly console interface

## Technologies Used

* Python
* Random Module
* Loops and Conditional Statements
* Lists and Dictionaries

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

python hangman.py
